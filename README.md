# PaintJitsu downloads

This public repository distributes signed PaintJitsu Android APKs and update metadata. The application source is maintained separately in a private repository.

- [Download the latest APK](https://github.com/NeonFoundry/PaintJitsu-Releases/raw/refs/heads/main/PaintJitsu.apk)
- [Versioned releases](https://github.com/NeonFoundry/PaintJitsu-Releases/releases)

Install the permanent-key edition once, then use **Updates → Check for updates** inside PaintJitsu. Android asks you to approve installation. Updates preserve your paintings.

Older temporary-key builds may require a one-time uninstall. Export your paintings before uninstalling, then import them after installing this edition.

`update.json` includes the version, APK size and SHA-256 checksum. PaintJitsu also checks the downloaded app's package and signing certificate before handing it to Android's installer. No account is required. Checking for updates or downloading an APK contacts GitHub; painting works offline.
